================================================================================
                         API ENDPOINTS
================================================================================

Authentication:
POST   /api/auth/register       - Register new user
POST   /api/auth/login          - Login user
GET    /api/auth/me             - Get current user

Chats:
POST   /api/chats               - Create/fetch chat
GET    /api/chats               - List user chats
GET    /api/messages/:chatId    - Get paginated messages

FCM Tokens:
POST   /api/tokens              - Register device token
POST   /api/notify/user         - Send FCM to user
POST   /api/notify/tokens       - Send FCM to tokens
POST   /api/notify/topic        - Send FCM to topic

================================================================================
                         WEBSOCKET EVENTS
================================================================================

Client → Server:
✅ join_chat          - Join chat room
✅ send_message       - Send message
✅ leave_chat         - Leave chat room

Server → Client:
✅ new_message        - New message received
✅ user_online        - User came online
✅ user_offline       - User went offline
✅ error              - Error occurred

================================================================================
                         DATABASE SCHEMA
================================================================================

User Collection:
{
  _id: ObjectId,
  name: String,
  email: String (unique),
  passwordHash: String,
  createdAt: DateTime,
  updatedAt: DateTime
}
Index: email

Chat Collection:
{
  _id: ObjectId,
  members: [ObjectId, ObjectId],
  lastMessage: String,
  lastMessageAt: DateTime,
  createdAt: DateTime,
  updatedAt: DateTime
}
Indexes: members, updatedAt

Message Collection:
{
  _id: ObjectId,
  chatId: ObjectId,
  senderId: ObjectId,
  text: String,
  createdAt: DateTime
}
Indexes: chatId+createdAt, senderId

Token Collection:
{
  _id: ObjectId,
  userId: ObjectId,
  token: String (unique),
  platform: String,
  lastSeenAt: DateTime,
  createdAt: DateTime,
  updatedAt: DateTime
}

Frontend:

  # Update API endpoints in code

    -H "Content-Type: application/json" \
